Blobbie Dash — Character Assets

These are the pieces from manifest.json (SVG only). Replace any file in svg/ with your own SVG export of the same name. To change which piece is used for which game state, edit ROLES in public/js/character.js. For a real run animation, add frame files (e.g. run_01.svg, run_02.svg) and set run to an array of their names.
